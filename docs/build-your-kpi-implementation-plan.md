## 2. Detailed Specifications of the Three Modes

### Mode 1: Visual KPI & Widget Builder (Standard Definition)
*Matches user's reference Screenshot 2 & 1:*
* **Purpose:** Allows business users to build deterministic KPI metrics and charts without writing code or prompts.
* **Input Controls:**
  * **KPI / Chart Title:** Text input (e.g., `Net Revenue by Region`).
  * **Target Measure:** Dropdown populated from active semantic model measures (`All Records (*)`, `NetRevenueUSD`, `GrossMarginUSD`, `Quantity`, etc.).
  * **Aggregation:** Dropdown (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`).
  * **Group By Dimension:** Dropdown (`No grouping (single stat)`, `Region`, `Country`, `Category`, `MonthName`, etc.).
  * **Display Visualization Style:** Clickable icon tiles:
    `[ 123 Stat KPI ]` `[ Bar Chart ]` `[ Line Trend ]` `[ Pie Dist. ]` `[ Scatter ]` `[ Data Table ]`
* **Actions:**
  * **"Save Definition Proposal"** (Primary blue button).
* **Output / Destination:**
  * Saves to the **"Configured Definitions"** stream (Screenshot 1).
  * Includes inline `Preview Live` (with formatted `$34.09M` values), `Edit Query`, `Approve / Reject`, and `Include on Dashboard` toggle.

---

### Mode 2: AI Core Custom Graph (Prompt-Driven with 10 Steps)
*Powered by `python_graph_agent.py` and SAP AI Core GPT-4o-mini:*
* **Purpose:** Generates advanced, custom statistical visualizations (Heatmaps, Correlation matrices, Pareto charts, Seaborn distributions) using natural language prompts.
* **10-Step Workflow Execution:**
  1. **Step 3:** Receive prompt + dataset path.
  2. **Step 4:** Inspect dataset schema, dtypes, and value ranges.
  3. **Step 5:** GPT-4o-mini interprets prompt $\rightarrow$ chart type, columns, aggregation.
  4. **Step 5b:** Deterministic pre-computation of numeric result set.
  5. **Step 5c:** Dual-path reconciliation and verification.
  6. **Step 6:** Generate isolated temp Python script (`temp_graph_<id>.py`).
  7. **Step 7:** Execute Python script with 60s timeout inside execution sandbox.
  8. **Step 8:** Read high-res PNG $\rightarrow$ Base64 data URI $\rightarrow$ return to caller.
  9. **Step 9:** Auto-delete temp `.py` script and `.png` image.
  10. **Step 10:** Stateless verification and memory cleanup.
* **UI Controls:**
  * Natural language prompt textarea with shortcut indicator (`⌘ Enter`).
  * Quick-prompt suggestion pills:
    * *"Seaborn distribution heatmap of Gross Margin across Sales Regions"*
    * *"Pareto 80/20 cumulative revenue analysis by Product SKU"*
    * *"Monthly margin trend violin plot with outlier detection"*
  * Live **10-Step Progress Stepper** showing stage progression (`Step 4 Schema Inspection` $\rightarrow$ `Step 5b Pre-computation` $\rightarrow$ `Step 7 Runtime Execution`).
* **Output:**
  * High-res rendered chart canvas with download button.
  * Executive AI insights generated by GPT-4o-mini.
  * Dual-path reconciliation badge (`Verified: 20,000 Source Records`).

---

### Mode 3: Data-Driven Automated Custom Graph (No Prompt Required)
*Combines the 10-step Python Graph Agent with structured visual data controls:*
* **Purpose:** For users who want the advanced Seaborn/Matplotlib visual power of `python_graph_agent.py` without needing to write a text prompt.
* **"Data Shown Options" Controls:**
  * **Metric Picker:** Multi-select or single measure (`NetRevenueUSD`, `GrossMarginUSD`, `Quantity`, etc.).
  * **Dimension Picker:** Dimension (`Country`, `SalesRegion`, `Category`, `MonthName`, etc.).
  * **Advanced Python Chart Type:**
    * `Seaborn Heatmap / Correlation Matrix`
    * `Waterfall Revenue Bridge`
    * `Treemap Hierarchical Breakdown`
    * `Violin Distribution Plot`
    * `Box Plot (Quartiles & Outliers)`
    * `Stacked Proportional Bar`
  * **Color Theme / Palette:** `Seaborn Blues`, `Viridis`, `Magma`, `Corporate Slate`.
  * **Sort & Top-N Limiter:** `Top 5`, `Top 10`, `All Categories`, `Ascending / Descending`.
* **Execution Flow:**
  * The frontend constructs the validated structured query plan and synthesizes the execution parameters.
  * Calls the backend agent to execute the same 10-step dual-path reconciliation pipeline.
* **Output:**
  * High-res Seaborn/Matplotlib chart image.
  * Summary table showing the pre-computed exact figures (`records_matched`, totals, verified status).

## 3. Backend API Route Specification

Update `backend/api/routes/graph.py` to provide direct execution for both prompt and data-driven requests:

```python
class PythonGraphAgentRequest(BaseModel):
    prompt: Optional[str] = None
    query_plan: Optional[Dict[str, Any]] = None
    metric: Optional[str] = None
    dimension: Optional[str] = None
    chart_type: Optional[str] = None

@router.post("/python-agent/generate")
def generate_python_graph(req: PythonGraphAgentRequest):
    """
    Executes the 10-step PythonGraphAgent workflow.
    Supports natural-language prompt OR structured data options.
    """
    from api.services.python_graph_agent import python_graph_agent
    
    # Synthesize prompt if using Mode 3 (data shown options without prompt)
    prompt = req.prompt
    if not prompt and req.metric and req.dimension:
        prompt = f"Generate a {req.chart_type or 'bar'} chart of {req.metric} by {req.dimension}"
    
    result = python_graph_agent.generate_custom_graph(
        prompt=prompt or "Overview of sales metrics",
        query_plan=req.query_plan
    )
    return result
```
